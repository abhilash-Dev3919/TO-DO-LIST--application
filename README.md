# ABHI TO DO LIST
A simple command-line To-Do List application developed using Python.
This is my second Python project, created to practise and apply the Python concepts I have learned.
##  Features
- User login with username validation.
- Add multiple tasks.
- Display all available tasks.
- Delete tasks using task numbers.
- Handle invalid menu inputs.
- Validate task numbers before deletion.
- Display appropriate messages when the task list is empty.
## Technologies Used
- Python
- Lists
- While Loop
- Match-Case
- If-Else Statements
- Try-Except
- Enumerate()
- List Methods (`extend()`, `pop()`)
